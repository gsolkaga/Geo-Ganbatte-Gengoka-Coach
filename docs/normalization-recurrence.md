# 消すのは対処であり、直すのは修理である

`npm run normalize:keys` を 2 回回して比べた実測（2026-08-18、各 10 リクエスト）。
AI を使わない検証部分は消費 0。

## 何をしたか

1 回目のあと、`tools/fix-normalization-errors.mjs --apply` で
**8 件の誤った用語 ID を正解タグから外した。**

そのうち **1 件だけは、辞書側の書き方も直した。**

```
q-tr-01（正解 TR）script = ref_lang_cyr_kazakh_letters
  トルコの出題にカザフ語のキリル字が割り当てられた

原因はこちらの plain の書き方だった
  カザフ語 Қ     「K の右下にヒゲが出ている」
  トルコ語 ş ç   日本語では「下にヒゲ」とも呼ばれる

文字体系を先に書く形へ直した
  「キリル文字で、K の右下に下向きのヒゲが付いた字がある」
  「アルファベットで、s や c の下に小さなヒゲ（セディーユ）が付いている」
```

残る 7 件は**正解タグから消しただけ**である。辞書は触っていない。

> **消すのは対処であり、直すのは修理である。**

出力を消して回ったところで、次に回せば同じものが出てくる。
`fix-normalization-errors.mjs` は**検出器としては正しく働くが、
これを掛け続けるのは治療ではない。**

## 再発した 7 件は何を要求しているか

`q-is-01` の例が分かりやすい。

```
記述  背の低い草？苔？が草原のように広がっている
辞書  ref_flora_open_grassland_gentle_hills（該当国 LU UY）
```

**アイスランドの出題にルクセンブルクとウルグアイが出た。**
辞書側に「樹木の無い苔と草の原」に近い用語が 2 つあり、
どちらもアイスランドではない国のリストを持っていた。
`ref_flora_grass_only_no_trees`（IS）は拾われたが、
似た用語がもう 1 つ拾われてしまった。

つまり要求はこうである。

- **似た用語同士を、素人語のレベルで区別できるように書き直す**
- 区別できないなら、**同じ用語に統合する**

`ref_camera_*` の 2 件も同じ構造である。カザフスタンの出題に
「短くて太いアンテナ」「下に白いトラックの車体」が割り当てられたが、
該当国に KZ が入っていない。**カーメタの軸は撮影世代に依存する**ため、
出典の該当国が今の撮影と合っていない可能性がある。

## 副産物: 正規化は決定的ではない

同じ入力で 2 回回して、**結果が一致しなかった。**

```
1 回目  q-ru-01 road_marking = road_marking_center_white
                            + ref_road_marking_center_white(85)
                            + ai_road_marking_02 + ai_road_marking_03
2 回目  q-ru-01 road_marking = road_marking_center_white
                            + ai_road_marking_02 + ai_road_marking_03
```

`ref_road_marking_center_white`（85 カ国）が 2 回目は拾われず、
`q-ru-01` の到達が **10 カ国 → 11 カ国**に戻った。

**辞書も記述も変えていない。** 同じ問いに同じ答えが返るとは限らない。
到達の数字を「この辞書の性能」として一度の測定で語ってはならない。

## 鏡像の検出は空振りしたが、誤りは起きていた

半球の 3 語を足したときに用意した検出は、両方とも 0 件だった。

```
正解国を消す用語（excludes が正解国を含む）  0 件
互いに紛らわしい用語が同じ欄に両方入る      0 件
```

**それでも南北の取り違えは起きていた。** 検出できなかっただけである。

```
記述    木の陰が北側に出ている
割当    ref_sun_shadow_to_north（98 カ国。太陽が南＝北半球側）
結果    24 カ国 → 21 カ国（温帯の南半球 LS NZ SZ が消えた）
```

著者に確認して分かった意図はこうだった（2026-08-18）。

```
木の陰が北側から（太陽がさして）影が出ている
  → 日差しが北から来ている → 太陽が北 → **南半球側**
```

**「影が北側」は日本語として二通りに読める。**
「影が北へ伸びる」とも「北側から光が来て影ができる」とも読める。
こちらは前者と読んで、**別名を逆の用語に付けていた。**

> **曖昧な言葉に別名を付けるとき、どちらに付けたかは記録に残らない。**

検出をすり抜けたのは、AU を熱帯側に分類していたためである
（国境の一部でも回帰線にかかる国は熱帯側に寄せる方針）。
AU は北部が熱帯にかかるので `excludes` に入らず、正解国が消えなかった。

つまり保守的な分類は、**正解を守ると同時に誤りを隠していた。**

```
温帯の南半球に分類していたら → AU が消えて検出器が鳴った（誤りは分かる）
熱帯に分類していたら         → AU は残るが誤りは隠れる（今回）
```

どちらが良いかは自明ではない。**候補を消さない方を選ぶのは正しい**が、
**「消さないから気づかない」という代償がある。**
気づく仕組みは別に必要である。今回は人間の指摘で分かった。

### 直したこと

1. **用語 ID を「太陽の位置」で付け直した。** 影の向きを主語にしない
   - `ref_sun_shadow_to_south` → `ref_sun_from_north`
   - `ref_sun_shadow_to_north` → `ref_sun_from_south`
2. 素人語と別名を太陽の位置だけで書いた（「真昼の日差しが北から来ている」）
3. 「木の陰が北側に出ている」を**著者の意図した側にだけ**別名として置き、
   note に「この言い回しはここに入れる／ここに入れない」と両方へ書いた
4. 正解タグの `q-au-01` を差し替えた → **24 カ国 → 17 カ国**

消しただけの 7 件と違い、これは辞書を直したので再発しない。

### 無言は情報にならないが、言及は弱い情報になる

同じ指摘でもう 1 つ分かった。

> わざわざ北半球であると言及する北半球住みの人間は少ないと思います。
> 太陽や影に言及していたら南半球であるくらいのゆるい判定でも良いかもしれません。
> **あくまで弱い推測ですので、違っていても AU を削って良い理由にはなりにくいです。**

非対称である。

```
言及なし  「影が判別できない」か「北半球」のどちらか → 情報にならない
言及あり  南半球かもしれない                        → 弱い推測
```

最初はこれを「情報量としては強い」と書いた。**それは行きすぎだった。**
弱い推測で候補を消してはならない。

そもそもこれは用語にできない。用語は**「見えたもの」を国に対応させる仕組み**であり、
「その人が言及したこと」は見えたものではない。
`note` に書いて説明の材料にするだけにとどめた。

学習者の居住地にも依存する。南半球在住の学習者では逆になる。
`recognition`（視認可能性）を計算せず人手で記録すると決めたのと同じ線引きである。

> **観察者の性質を、地点の性質として使ってはならない。**

### 方位そのものは強い。だから読み違えが高くつく

言及の有無は弱いが、**実際に方位を読めたなら結論は強い。**
`ref_sun_from_north` は温帯の北半球 56 カ国を一度に消す。

強いものは外したときの損害も大きい。今回それが起きた。
`note` に「使う前に方位を確かめること」と、
実際に逆に解釈された事例を書いた。

> **一番強い手がかりが、一番危ない。**
