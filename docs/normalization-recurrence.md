# 消すのは対処であり、直すのは修理である

`npm run normalize:keys` を 2 回回して比べた実測（2026-08-18、各 10 リクエスト）。
AI を使わない検証部分は消費 0。

## 何をしたか

1 回目のあと、`tools/fix-normalization-errors.mjs --apply` で
**8 件の誤った用語 ID を正解タグから外した。**

そのうち **1 件だけは、辞書側の書き方も直した。**

```
q-tr-01（正解 TR）script = ref_lang_cyr_kazakh_letters
  トルコの出題にカザフ語のキリル字が割り当てられた

原因はこちらの plain の書き方だった
  カザフ語 Қ     「K の右下にヒゲが出ている」
  トルコ語 ş ç   日本語では「下にヒゲ」とも呼ばれる

文字体系を先に書く形へ直した
  「キリル文字で、K の右下に下向きのヒゲが付いた字がある」
  「アルファベットで、s や c の下に小さなヒゲ（セディーユ）が付いている」
```

残る 7 件は**正解タグから消しただけ**である。辞書は触っていない。

> **消すのは対処であり、直すのは修理である。**

出力を消して回ったところで、次に回せば同じものが出てくる。
`fix-normalization-errors.mjs` は**検出器としては正しく働くが、
これを掛け続けるのは治療ではない。**

## 再発した 7 件は何を要求しているか

`q-is-01` の例が分かりやすい。

```
記述  背の低い草？苔？が草原のように広がっている
辞書  ref_flora_open_grassland_gentle_hills（該当国 LU UY）
```

**アイスランドの出題にルクセンブルクとウルグアイが出た。**
辞書側に「樹木の無い苔と草の原」に近い用語が 2 つあり、
どちらもアイスランドではない国のリストを持っていた。
`ref_flora_grass_only_no_trees`（IS）は拾われたが、
似た用語がもう 1 つ拾われてしまった。

つまり要求はこうである。

- **似た用語同士を、素人語のレベルで区別できるように書き直す**
- 区別できないなら、**同じ用語に統合する**

`ref_camera_*` の 2 件も同じ構造である。カザフスタンの出題に
「短くて太いアンテナ」「下に白いトラックの車体」が割り当てられたが、
該当国に KZ が入っていない。**カーメタの軸は撮影世代に依存する**ため、
出典の該当国が今の撮影と合っていない可能性がある。

## 副産物: 正規化は決定的ではない

同じ入力で 2 回回して、**結果が一致しなかった。**

```
1 回目  q-ru-01 road_marking = road_marking_center_white
                            + ref_road_marking_center_white(85)
                            + ai_road_marking_02 + ai_road_marking_03
2 回目  q-ru-01 road_marking = road_marking_center_white
                            + ai_road_marking_02 + ai_road_marking_03
```

`ref_road_marking_center_white`（85 カ国）が 2 回目は拾われず、
`q-ru-01` の到達が **10 カ国 → 11 カ国**に戻った。

**辞書も記述も変えていない。** 同じ問いに同じ答えが返るとは限らない。
到達の数字を「この辞書の性能」として一度の測定で語ってはならない。

## 鏡像の検出は空振りした（それでよい）

半球の 3 語を足したときに用意した検出は、両方とも 0 件だった。

```
正解国を消す用語（excludes が正解国を含む）  0 件
互いに紛らわしい用語が同じ欄に両方入る      0 件
```

南北の取り違えは起きなかった。**空振りは検出器の失敗ではない。**
起きていないことを確認できたという結果である。

ただし `q-au-01` は危なかった。

```
記述    木の陰が北側に出ている
割当    ref_sun_shadow_to_north（98 カ国。影が北 = 太陽が南 = 北半球側）
結果    24 カ国 → 21 カ国（温帯の南半球 LS NZ SZ が消えた）
```

**オーストラリアは南半球である。** 大部分では正午の太陽が北にあり、
影は南へ伸びる。この記述は方位を取り違えている可能性が高い。

それでも AU が消えなかったのは、
**国境の一部でも回帰線の間に入る国を熱帯側に寄せた**からである
（`tools/add-hemisphere-terms.mjs`）。AU は北部が熱帯にかかるため
`ref_sun_shadow_to_north` の該当国に入っていた。

> **保守的に間違えたことが、正解を守った。**

もし AU を「温帯の南半球」に分類していたら、この観察は
**正解の国を候補から消していた。** 一番強い手がかりが一番危ない。
