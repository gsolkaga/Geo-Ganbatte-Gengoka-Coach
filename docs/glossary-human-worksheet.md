# 用語辞書の人手記述ワークシート

**この表に書く。`data/glossary-human.json` を直接編集しない。**
8/17 に Kiro が JSON へ変換する（リクエストは消費しない）。

出典は GeoGuessr プレイヤー（最高到達 Master 4）の知識。

## 書き方

| 列 | 内容 |
|---|---|
| `plain` | **口語でよい。**「棒ぜんぶが黄色い」のような言い方をそのまま書く |
| `countries` | ISO 3166-1 alpha-2 をスペース区切り（`IS` `VN KH` `ES EE LV`） |
| `混同` | 取り違えやすい相手。**同じ表の別行を指す。** 空欄でよい |
| `備考` | 見る手順、条件、注意。空欄でよい |

**`canonical`（正規用語）は書かなくてよい。** `plain` と `countries` があれば Kiro が起こせる。

## 3 つのルール

**1. 迷ったら空欄にする。** 誤った値より空欄が安全である。
Kiro が動かないので検証が走らない。埋めることを目的にしない。

**2. 属性の組み合わせで分ける。単一属性で括らない。**
これが AI との最大の差だった。「黄色いボラード」という単位は存在せず、
黄色がどこにあるかで国が分かれた。

```
本体全体が黄色                  → IS
本体が白、反射板が黄色、帯あり   → DK
本体が白、反射板が黄色、帯なし   → BE
黄色の周囲に黒                  → ES EE LV
```

**「どこが」「何色で」「他に何があるか」まで書く。**

**3. 見る手順も書く。**
「裏まで赤い（NZ）」は正面だけ見ていては永久に判別できない。
**振り返って裏を見るという行為が知識に含まれている。**
AI は 4 モデルすべてがこの軸を作れなかった。**ここが人間の独占領域である。**

## 参考：メタの強さの区分

Kiro が変換時に判定するので**書かなくてよい**が、記述の粒度の目安になる。

| 区分 | 条件 |
|---|---|
| 最強メタ | 1 カ国に確定、またはリージョンまで絞れる |
| 強メタ | 2 カ国（近接） |
| 良メタ | 3〜4 カ国（**近接であることが条件**） |
| 補助メタ | それ以上、または**大陸をまたぐ**。単独では主役になれない |

**同じ 3〜4 カ国でも大陸が違えば良メタではない。** 失点が距離で決まるためである。

**補助メタも書く価値がある。** 「絞り込めていない」ことを学習者に教えるために必要であり、
組み合わせの材料にもなる（左側通行 24 カ国 ＋ 繁体字 2 カ国 = 香港 1 カ国）。
