## 注意：休暇中は単独作業になる

Kiro が動かないため、**衝突は起きない。** ただし逆に、
**書いた内容の検証も走らない。**

- Markdown の表の列がずれていても誰も気づかない → **8/17 に Kiro が検証する**
- 用語の該当国コードが間違っていても検出されない → 同上
- **だから空欄を恐れないこと。** 誤った値より空欄の方が安全である

これは本プロジェクトで繰り返し確認したことと同じである。
**`unknown` は減点ではない。誤った値を埋められる方が困る。**
