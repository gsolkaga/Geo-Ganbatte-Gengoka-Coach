# Geo-Ganbatte-Gengoka-Coach（GGG）

Street View 上の風景を見て、気づいた特徴を**言語化する**練習をし、その言語化の質を AI が採点・添削する学習アプリ。GeoGuessr の初級〜中級プレイヤーを対象とする。

**AI が画像を見て場所を当てるアプリではない。** 画像を見るのは人間であり、AI は人間が書いた観察メモを解釈・評価する役に限定している。

> **試す方へ。** 自分の API キーが必要で、誤った使い方をすると課金が発生する箇所がある。
> 動かす前に [資格情報と課金の境界](docs/credentials-and-billing.md) を読むこと。
> **このアプリは認証を持たない。公開ホスティングしないこと。**

## 何をするものか

風景を見て、14 の欄に気づいたことを書く。書いたものが採点される。

```
風景を見る → 14 の欄に書く → 採点
                              ├ コード  見落とし・回答の正誤・絞り込みの計算
                              └ AI      素人語から用語への変換・記述の評価・解説
```

原則は 1 つ。**確実に判定できるものはコード、曖昧さの解釈が必要なものだけ AI。**

だから**画像認識はやらせない。** 規約の問題もあるが、それ以上に
**AI が場所を当ててしまうと学習者が観察しなくなる。**

鍛えるのは知識でも速度でもなく、**「何を見て、どう判断するか」の結合**である。
GeoGuessr のメタ知識は [Plonk It](https://www.plonkit.net/) に既に整理されている。
足りないのは資料ではなく、**それを実戦で想起する訓練**である。

## 動かす

```bash
npm install
cp .env.example .env      # PowerShell: Copy-Item .env.example .env
# .env を編集して 3 本の鍵を設定する
npm run dev               # http://localhost:3000
```

Node.js 20 以上。**採点 1 回に 20〜30 秒かかる**（モデルによる。仕様である）。

詳しくは [動かし方](docs/setup.md)。

## 画面は 3 つ

**`/` だけが学習者向けで、残る 2 つはデータを書き換える。**

| 画面 | 何をするか | 消費 |
|---|---|---|
| `/` | 風景を見て書き、採点を受ける | 1 プレイ 2 |
| `/admin` | 問題集を作る。正解タグを付ける。**配色が違う** | **0** |
| `/datasets` | データセットを取り込み、切り替える | **0** |

`/admin` は学習画面と同じ入力部品を使い回している。**部品が同じだと画面を取り違える**ので、
配色を分けた（学習画面は白地とスレート、編集モードは濃い藍と琥珀）。

> **取り違えると教材が壊れる画面は、見た瞬間に違うと分かること。**

画面ごとの構造と、そうした理由は [画面の説明](docs/screens.md)。

## 消費と課金

さくらの AI Engine の無償枠は**月 3,000 リクエスト。** 1 プレイで 2 消費する。

| | 消費 |
|---|---|
| 採点 1 回 | 2（採点 + 添削） |
| Street View の表示（Maps Embed API） | 無料・無制限 |
| pano のメタデータ照会 | 無料・クォータも消費しない |
| `/admin` `/datasets` の全操作 | **0** |
| `tools/` の測定・監査すべて | **0** |

**課金が発生しうる箇所がある。** 既定では無効にしてあるが、
有効にすると Street View Static API が呼ばれる（NoMove 表示）。
必ず [資格情報と課金の境界](docs/credentials-and-billing.md) を読むこと。

## Street View の扱い

- 画像データを保存・キャッシュしない（規約により禁止されている）
- 画像を AI へ送信しない
- **保存するのは pano ID と座標のみ**（pano ID は無期限の保存が許容されている）
- 著作権表記が Google 提供のパノラマのみを採用する
- **このリポジトリに画像ファイルは 1 枚も含まれていない**

最後の 1 行は規約ではなくコードで守っている。`.gitignore` で画像の拡張子を除外し、
配布データの検証でも画像への参照を弾く。`git ls-files` に画像が 1 件も出ないことで確かめられる。

> **規約で禁止されていることを、コードで不可能にする。**

## 学習用データセット

出題と用語辞書をまとめて配れる。**正解データを配って終わりにしない。**

```bash
npm run dataset -- export --name "..."   # 配る側
npm run dataset -- install <file>        # 受け取る側
npm run dataset -- use <id>
```

**画面（`/datasets`）からも同じことができる。** 取り込み・切り替え・削除に加えて、
書き出しも画面から行える（`GET /api/dataset-export`）。
CLI と同じ `shared/dataset.ts` の関数を使うので、**出てくるファイルの中身は同じである**
（キーの並びだけ違う。API は Zod を通すため）。

書き出しは**検証に通らなければファイルを渡さない。** 画像への参照が
1 件でも混ざっていれば `422` で止まり、どこが悪いかを画面に出す。

> **配る前に止めるのが、配る人を守ることである。**

書き出しは**名前と作成者を聞かない。** 問題集を作った時点（`/admin`）と
受け取ったものを使う時点（切り替え）で `data/library.json` に記録している。
聞くと二度書かせるだけでなく、**他人のデータに自分の名前を入れて出せてしまう。**

由来が記録されていなければ `409` で止める。`data/library.json` は
利用者ごとの状態なので `.gitignore` に入っており、**clone した直後は由来が無い。**
そこで既定値を当てると `author: "unknown"` の配布物が黙って出来る。

> **持っていない権利を許諾できないのと同じで、書いていない名前を名乗らせない。**

手順と規律は [学習用データセットの配布と取り込み](docs/datasets.md)。

## 既知の限界

| | |
|---|---|
| **回答できる国は 102 カ国** | 全 200 弱ではない。`data/countries.json` にある国だけが候補に出る |
| **辞書の確かさは一様でない** | `certainty` が `verified` のものだけが断定に使える |
| **モデル間の一致は正しさを保証しない** | 4 モデルのうち 3 つが同一の誤りをした実測がある（ガーナの走行車線） |
| **認証が無い** | ローカル実行専用。`/admin` は誰でも教材を書き換えられる |
| **出題 ID が答えを含む** | `q-kr-01` の `kr` が国コードである。画面には出さないが、通信の中身には残る |

### 102 カ国について

`data/countries-seed.json`（人手作成）に載せた国だけを候補にしている。
候補にない国は**学習者が答えとして挙げられない。** これは限界である。

**増やすこと自体は 1 行で済む。** 絞り込み欄があるので、
102 でも 200 でも探す手間はほとんど変わらない（**だから ON/OFF 画面は作らない**）。

増やしていないのは手間の問題ではなく、**数字の意味が変わるから**である。
辞書の各用語は該当国を明示的な配列で持っているので、国を足しても
**その国はどの用語からも言及されない。** そして
`tools/combo-report.mjs` の「観察が国を示さない」の判定線は
`ceil(国数 / 2)` なので、国を倍にすると 51 件から 101 件へ動く。
**アスファルト舗装（102 カ国該当）が「絞り込みに使える」側へ化ける。**

> **母数を変えると、母数を使って出した判断がすべて動く。**

増やすなら順番がある。`countries-seed.json` と `data/regions.json` に足し、
`scripts/build-countries.mjs` を回し、`npm run combo` と
`node tools/coverage-report.mjs` を再生成して、報告書の数字を差し替える。
**学習者向けの絞り込み計算（`server/utils/narrowing.ts`）は国数に依存していない**ので、
そこは動かない。

```
.kiro/specs/geo-observation-coach/   要件・設計・タスク・補助文書
data/                                 教材データ、用語辞書、国定数テーブル、地域グループ
data/datasets/<id>/dataset.json       ライブラリ（配布形式そのまま。読むだけ）
data/library.json                     いま選ばれているものと、その由来（生成物）

scripts/                              検証・生成スクリプト、データセットの操作
tools/                                測定と監査（すべて消費 0）
shared/                               型と純粋な計算（**画面にもサーバにも道具にも共有する**）
app/pages/                            /（学習）/admin（編集）/datasets（配布）
```

`data/library.json` と `data/progress.json` は**利用者ごとの状態**なので
`.gitignore` に入れてある。一覧は `data/datasets/` を走査して作るので、
索引が無くても復元できる。

> **置いてあるものが一覧である。索引を正典にしない。**

読めなくなる。**全選択して反転させるまで気づけなかった**（実測 2026-08-19）。

> **色は継がれる。継いで困る場所で断ち切る。**

## 注意事項

- Plonk It の内容は**人手検証の一次情報源として参照するのみ**であり、このリポジトリのデータには取り込んでいない（© 2021-2026 Plonk It）
- `GeoGuessr` は GeoGuessr AB の商標である。本プロジェクトは非公式であり、関係はない
- 用語辞書と国定数テーブルは AI が生成したものを含む
  - 国定数テーブル（`data/countries-merged.json`）は `verifiedByHuman` が `false` の項目が**人手検証を経ていない**
  - 用語辞書（`data/glossary.json`）は `certainty` で確かさを持つ。**断定に使えるのは `verified` のみ**
    - `verified` 人間が一次情報で確認した
    - `heuristic` 実戦中の連想・経験則。**人間が書いたが検証されていない**（27 語のうち 18 語）
    - `unverified` AI 生成で人手検証を経ていない
- **モデル間の一致は正しさを保証しない。** 4 モデルのうち 3 モデルが同一の誤りをした実測がある（ガーナの走行車線）
- **由来（`source`）と確かさ（`certainty`）は別である。** 人間が書いたことは正しいことを意味しない

## 名前の由来

**G**eo **G**anbatte **G**engoka Coach。`Gengoka`（言語化）が中核である。GeoGuessr の `GG`（Good Game / Good Guess）エモートと掛けている。
