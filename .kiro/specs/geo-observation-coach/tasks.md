# Implementation Plan

## Overview

稼働状況に合わせて 3 フェーズに分割する。

- **Phase 1（8/7 フル稼働）** — v1 が動く最小セット。見落とし判定・正規化・辞書は含まない
- **Phase 2（8/8〜8/16 断続）** — 細切れで進められる作業。辞書生成、タグ付け、検証スクリプト
- **Phase 3（8/17〜8/19 フル稼働）** — v2 の判定ロジックと比較、記事用データの取得

Phase 1 の完了時点で「やってみた。面白くない」の記録が取れる状態になる。これが記事の中核素材である。

v1 は正解タグと用語辞書を持たないため、見落とし判定（`grading.ts`）と正規化（`normalize`）を必要としない。この 2 つを Phase 3 に回せることが、8/7 の実装量を抑える鍵である。

順序の要点。

- **6 と 7 は 12 より先**（メタデータ照会がないと著作権表記を確認できず、出題データを作れない）
- **11 は 7・8・9・10 が揃ってから**（学習モードの統合が Phase 1 のゴール）
- **13 は Phase 1 の最終タスク**（ここで記事の中核素材が取れる）
- **16 は 15 の後**（生成結果がないと人手検証できない）
- **22・23 は Phase 3**（辞書とタグが揃うまで着手不能）
- **21 は独立**（8/7 に投げた出力があれば、いつでも進められる）

    - **学習者の注意が AI の比較に向くと目的から逸れる。** 風景の観察が AI の観察になる
