# スロット定義（確定文言）

14 スロットの表示文言。実装ではこの表の内容を定数として持つ。

## 設計方針

- **ラベルは平易な表現を主とし、正規用語は括弧で添える。** 「ボラード」だけでは初心者に伝わらない
- **プレースホルダは素人語で書く。** 学習者に期待する粒度と語彙水準を示すのが目的
- **補助テキストで「どこを見るか」を示す。** 何を見るべきか分からないことが観察漏れの原因である
- `script` には「読めなくて OK」と明記する。読めないから空欄にする、という挙動を防ぐ

## 定義

### 1. `traffic_side`

| 項目 | 内容 |
|---|---|
| ラベル | 車はどちら側を走っている？（走行車線） |
| プレースホルダ | 右側通行 |
| 補助 | 対向車、停車中の車の向き、追越車線の位置から判断する |

### 2. `road_marking`

| 項目 | 内容 |
|---|---|
| ラベル | 道路の白線・黄線（路面標示） |
| プレースホルダ | 白い破線の中央線、路肩に線はない |
| 補助 | 中央線の色（白か黄）、実線か破線か、路肩線の有無と色 |

### 3. `bollard`

| 項目 | 内容 |
|---|---|
| ラベル | 車道脇の短い杭・ポール（ボラード） |
| プレースホルダ | 白い本体で上が黒、赤い反射板つき |
| 補助 | 断面の形（丸・角・三角）、色の組み合わせ、反射板の色と数、高さ |

### 4. `pole`

| 項目 | 内容 |
|---|---|
| ラベル | 電柱・街灯の形 |
| プレースホルダ | 細いコンクリの柱、上が逆 L 字に曲がっている |
| 補助 | 素材（木・コンクリート・金属）、腕木の形、碍子の数、街灯の傘の形 |

### 5. `sign`

| 項目 | 内容 |
|---|---|
| ラベル | 標識の形・色 |
| プレースホルダ | 三角形で白地に赤い縁 |
| 補助 | 警戒標識の形（三角かひし形か）、縁の色、支柱の色と模様 |

### 6. `script`

| 項目 | 内容 |
|---|---|
| ラベル | 看板の文字（読めなくて OK、形を書く） |
| プレースホルダ | A の上に点が 2 つある文字、逆さの e みたいな字 |
| 補助 | **読めなくてよい。** 見た目を書く。アルファベット以外か、変わった記号や飾りが付いているか |

### 7. `ground`

| 項目 | 内容 |
|---|---|
| ラベル | 地面・土の色 |
| プレースホルダ | 赤茶色の土、白っぽい砂 |
| 補助 | 路肩や畑の土の色。赤土・黒土・白砂は絞り込みが強い手がかりになる |

### 8. `terrain_vegetation`

| 項目 | 内容 |
|---|---|
| ラベル | 地形・植生 |
| プレースホルダ | 急な山が近い、乾いた低木ばかり |
| 補助 | 平地か山か、乾燥か湿潤か、木の種類（針葉樹・ヤシ・ユーカリなど） |

### 9. `architecture`

| 項目 | 内容 |
|---|---|
| ラベル | 建物・屋根の形 |
| プレースホルダ | 赤い瓦屋根で白い壁 |
| 補助 | 屋根の材質と色、壁の材質、窓の形、塀や柵の作り |

### 10. `vehicle`

| 項目 | 内容 |
|---|---|
| ラベル | 車・ナンバープレート |
| プレースホルダ | 黄色くて横長のナンバー |
| 補助 | ナンバーの色と縦横比、車種の傾向、ハンドルの位置 |

### 11. `pavement`

| 項目 | 内容 |
|---|---|
| ラベル | 車道の舗装 |
| プレースホルダ | 未舗装の砂利道、補修の跡だらけ |
| 補助 | アスファルト・コンクリート・未舗装、ひび割れ、補修痕の入り方 |

### 12. `camera`

| 項目 | 内容 |
|---|---|
| ラベル | 撮影車・カメラの世代 |
| プレースホルダ | 車の屋根が映り込んでいる、画質が粗くて色が薄い |
| 補助 | 車体の映り込み、機材の影、画質の粗さ、色調、ぼかしの入り方 |

### 13. `season`

| 項目 | 内容 |
|---|---|
| ラベル | 季節・太陽 |
| プレースホルダ | 葉が落ちている、影がとても長い |
| 補助 | 落葉・新緑・雪、影の長さと向き、日射の強さ |

### 14. `other`

| 項目 | 内容 |
|---|---|
| ラベル | その他の気づき（上のどれにも当てはまらないもの） |
| プレースホルダ | ゴミがまったく落ちていない、撮影者が歩いて撮っている |
| 補助 | 他のどのスロットにも入らない観察を書く。決め手になることがある |

**このスロットは辞書を育てる入口である。**

`other` に書かれた内容は用語辞書に該当する用語を持たないため、正規化は必ず「該当なし」になる。その記述は辞書追加候補として蓄積される（要件 3-4）。使われるほど辞書が育つ経路が、ここで成立する。

このスロットが必要になった経緯を記録しておく。

- **ルワンダはゴミが落ちていない**（刑罰に社会奉仕活動があるため）。清潔さを書く場所が 13 スロットのどこにもなかった
- **マダガスカルは Google カーではなくトレッカー（背負い式）で撮影されており、撮影者が写っている**。これは `camera` に入るが、同種の「撮影手法」の観察は他にもありうる

既存のスキーマに収まらない観察が実在することが判明したため、受け皿を設けた。**スキーマの穴は、実際に使ってみるまで見えない。**

タグ付けの負荷はほぼゼロである（多くの問題で空欄）。しかし決め手になる問題では、ここが唯一の正解経路になる。

## 状態の表示文言

| 値 | 表示 | 意味 |
|---|---|---|
| `visible` | 見えた | 写っていると判断した |
| `absent` | 見えない | 写っていないと判断した |
| `unknown` | 未確認 | まだ見ていない、判断していない |

**`absent` と `unknown` の違いを画面上でも説明する。** 「見えない」は判断の結果であり、「未確認」は観察漏れの候補である。この区別が失敗モードの診断の前提になる。

初期状態は全スロット `unknown` とする。

## 回答欄の文言

| 項目 | 表示 | 補足 |
|---|---|---|
| 候補国 | どこの国だと思う？（最大 3 つ） | 1 つでもよい |
| 確信度 | 高 / 中 / 低 | 「高」は 1 つだけ選べる |
| 決め手 | 一番の決め手にした項目 | スロットから 1 つ選ぶ |
| 総合推論 | なぜそう思ったか（任意） | 自由記述 |

確信度の補助文言。

- **高** — たぶんこれで合っている
- **中** — 可能性はある
- **低** — 念のため挙げておく

「高」を 1 つに制限する理由を画面に添える。「本命を 1 つ決めることが練習になります」程度の文言でよい。
